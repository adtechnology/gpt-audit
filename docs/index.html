Audit Google Publisher Tag & Ad Manager in Live Chrome

A universal coding agent plugin that drives Google's Chrome DevTools MCP to evaluate ad slots, network calls, correlators, consent strings, and 15 deterministic anomaly rules — all running 100% locally on your machine.

Setup & Configuration

Install on Every AI Agent

Follow the instructions for your preferred AI development environment. All three environments leverage the exact same underlying skills, rules, and scripts.

Google Antigravity Setup

Antigravity reads the plugin manifest (plugin.json), bundled MCP configuration (mcp_config.json), and background agent (agents/gpt-auditor.md).

Option 1: Global Installation (Recommended)

Terminal 
mkdir -p ~/.gemini/config/plugins
git clone https://github.com/adtechnology/gpt-audit.git ~/.gemini/config/plugins/gpt-audit

Option 2: Antigravity CLI (agy)

Terminal 
agy plugin install https://github.com/adtechnology/gpt-audit
agy plugin list --json
Note on MCP Server Name: If the built-in Chrome DevTools plugin is active in Antigravity settings (Settings → Customizations → Chrome DevTools), disable one to avoid duplicate server names.

Claude Code Setup

Claude Code loads the plugin via .claude-plugin/plugin.json and connects to Chrome DevTools MCP via .mcp.json.

Option 1: Marketplace Install

Prompting Guide

How to Use in Any Agent

Copy and paste these natural language prompts directly into your agent conversation thread.

"Audit the GPT setup on https://www.telegraph.co.uk/ and write the report to out/"
Executes the standard end-to-end audit: collects live slots, analyzes consent signals, parses network correlators, evaluates R01–R10, and generates report.md.
"Audit the GPT setup on https://edition.cnn.com/ and https://www.telegraph.co.uk/, compare them, and write reports to out/"
Audits both URLs in sequence, generates individual reports, and compiles out/comparison.md with a comparative matrix of slots, SRA status, Prebid versions, and anomalies.
"@gpt-auditor audit https://example.com/article"
Runs the audit in a background subagent in Google Antigravity, returning the report summary and file links upon completion without blocking your main conversation thread.
Publisher Policy Enforcement

Publisher Mandatory Parameters ("Pflichtparameter")

Enforce publisher tagging requirements — including PPID (Publisher Provided Identifier), mandatory targeting keys (cust_params and pageTargeting), slot constraints, and SafeFrame policies via gpt-audit.config.json.

Config Spec

gpt-audit.config.json

Place in your project root or pass via -c <config.json> to analyze and report tools:

gpt-audit.config.json 
{
  "publisher": "Example Media Network",
  "required": {
    "ppid": true,
    "custParams": ["section", "user_tier"],
    "pageTargeting": ["env", "edition"],
    "slotTargeting": ["pos"],
    "minSlots": 1,
    "requireSafeFrame": false
  }
}

Deterministic Engine

Anomaly Rules Catalog (R01–R16)

Rules are implemented as plain Node 22 ESM modules in scripts/rules/. No external LLM is involved in judging; the same page generates identical findings in every agent.

R01 High
Slot Defined but Never Displayed
Slot exists in pubads but has no queryId, no response, and was never named in an ad request.
Call googletag.display(id) or remove slot definition.
R02 High
DOM Container Missing or Duplicate
Container div does not exist in the DOM (dom.exists: false) or duplicate element IDs are defined.
Ensure unique container div exists in DOM with matching elementId.
R03 Medium
Unfilled Slot
Slot requested but returned empty (render.isEmpty: true). AdX/OB backfill is properly recognized as filled.
Check line-item targeting, price floors, and advertiser demand.
R04 Medium
No Requested Size Fits Viewport
All requested fixed sizes exceed viewport width (1x1 and fluid exempt).
Configure responsive sizeMapping or smaller creative sizes.
R05 Medium
Container Size Mismatch (CLS)
Container height differs from creative by > 2px, or container lacks reserved height (reservedHeight: false).
Reserve container min-height per breakpoint via CSS (CLS prevention).
R06 Low
Single Request Architecture Off
Multiple display ad requests fired independently without SRA batching (iu_parts). Video excluded.
Call googletag.pubads().enableSingleRequest() before enableServices.
R07 High
Mixed Correlators in Page View
More than one distinct correlator ID across display requests of a single page view. Video excluded.
Ensure all initial slots are batched; check for repeated display() calls.
R08 High
Initial Load Disabled, Never Refreshed
pubads().disableInitialLoad() is active but zero display requests were fired and no refresh occurred.
Add timeout fallback to invoke googletag.pubads().refresh().
R09 High
Consent Mismatch (GDPR / TCF)
gdpr=1 with empty TC string, or no __tcfapi, or Purpose 1 denied while omitting npa=1/ltd=1.
Ensure CMP passes valid TC string before GPT calls; set npa=1/ltd=1.
R10 Medium
Legacy or Duplicate gpt.js
Loaded from legacy googletagservices.com, multiple script tags, or tag lacks async attribute.
Load single async tag from securepubads.g.doubleclick.net/tag/js/gpt.js.
R16 High
Publisher Mandatory Parameter Missing
Snapshot or ad requests lack parameters specified in gpt-audit.config.json (e.g. PPID, cust_params, pageTargeting).
Ensure required parameters are set via pubads().setPublisherProvidedId() or targeting APIs.
R11 (Planned) High
Command Queue Never Flushed
cmdQueueLength > 0 after load and pubadsReady === false.
Verify googletag.enableServices() ran without uncaught callback errors.
R12 (Planned) Medium
Refresh Interval Under 30 Seconds
Probe recorded two slotRequested events for one slot less than 30s apart.
Enforce policy mandated 30-second minimum refresh intervals.
R13 (Planned) High
Targeting Contains PII / Oversized
Regex detected email/phone/UUID in targeting or ad request URL > 8 000 chars.
Hash or remove PII keys; trim excessive targeting parameters.
R14 (Planned) Medium
Prebid Keys Present Without Winning Bid
hb_* targeting present without bid response, or bidderTimeout lower than response times.
Review pbjs.setTargetingForGPTAsync() timing; raise bidderTimeout.
R15 (Planned) Low
Slot Never Viewable
No impressionViewable fired after full scroll pass; slot located far below the fold without lazy load.
Enable GPT lazy loading (googletag.pubads().enableLazyLoad()).

Zero Invalid Traffic

Strict Browser Guardrails

Automated web auditing must protect publisher integrity. These non-negotiable rules govern every execution.

🚫

Never Touch Ad Creatives

The agent never clicks, hovers, focuses, or scrolls into any google_ads_iframe_* or ad creative. Clicking ads constitutes invalid traffic (IVT).

🔒

Read-Only Execution

Never calls googletag.display(), pubads().refresh(), or destroySlots() on third-party pages.

🍪

CMP Auto-Accept Only

Accepting the cookie consent dialog is the only permissible click in an entire audit run. Never rejects or explores settings.

⚡

Single Load Guarantee

Exactly one page load per URL. No automatic retries or reload loops.

Developer & CI Automation

Standalone CLI Pipeline

Run the parser, analyzer, and reporter directly in Node.js without driving a browser.

Terminal (Node 22 ESM) 
# 1. Parse raw MCP DevTools output to structured network.json
npm run extract -- out/www.telegraph.co.uk/network-raw.txt -o out/www.telegraph.co.uk/network.json

# 2. Run deterministic rule engine (R01-R10)
npm run analyze -- out/www.telegraph.co.uk/snapshot.json out/www.telegraph.co.uk/network.json -o out/www.telegraph.co.uk/findings.json

# 3. Generate report.md and report.json
npm run report -- out/www.telegraph.co.uk/snapshot.json out/www.telegraph.co.uk/network.json out/www.telegraph.co.uk/findings.json -o out/www.telegraph.co.uk/

# 4. Multi-host comparison
node skills/gpt-audit/scripts/report.js --compare out/*/report.json -o out/comparison.md
